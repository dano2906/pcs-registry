# Resumen

**Our Pieces** es un registro de código abierto construido sobre shadcn-vue. Su misión principal es cerrar la brecha entre los ecosistemas de React y Vue portando componentes populares y de alta calidad de React a Vue 3 con facilidad y precisión.

Este proyecto **no** es un producto SaaS ni una biblioteca de componentes en el sentido tradicional. En cambio, es una colección de componentes listos para copiar y pegar, diseñados para integrarse directamente en tu base de código, dándote total propiedad y control.

### ¿Por qué Our Pieces?

El ecosistema de Vue es vibrante, pero a menudo se queda atrás con respecto a React en cuanto al volumen de componentes de UI de alta calidad disponibles, especialmente aquellos compatibles con la filosofía moderna "headless" o "radix-ui" popularizada por shadcn/ui.

Our Pieces busca resolver esto enfocándose en:

1.  **Enriquecer el Ecosistema**: Identificamos activamente componentes útiles de React que faltan o están subrepresentados en Vue y los portamos.
2.  **Distribución Flexible**: Los componentes están diseñados para ser copiados y pegados o instalados vía CLI, permitiendo la máxima flexibilidad.
3.  **Alta Personalización**: Dado que eres dueño del código, puedes estilizar y modificar los componentes para que se ajusten a tus necesidades exactas sin luchar contra la API de una biblioteca.
4.  **Estándares Modernos**: Todos los componentes utilizan la sintaxis moderna de Vue 3, incluyendo Composition API, TypeScript y `<script setup>`.
5.  **Impulsado por la Comunidad**: Estamos abiertos a contribuciones. Si ves un componente de React que te encanta, ayúdanos a traerlo a Vue.

# Contribuir

¡Nos encanta tu colaboración! Queremos que contribuir a **Our Pieces** sea lo más fácil y transparente posible, ya sea reportando un error, discutiendo el estado actual del código, enviando una corrección o proponiendo nuevas características.

## Problemas (Issues)

Usamos GitHub Issues para rastrear errores públicos y solicitudes de funciones.

### Crear un nuevo Problema

Si encuentras un error o tienes una solicitud de función, por favor [abre un nuevo issue](https://github.com/dano2906/pcs-registry/issues).

**Los Grandes Reportes de Errores** suelen tener:

- Un resumen rápido y/o antecedentes.
- Pasos para reproducir (¡sé específico!).
- Lo que esperabas que sucediera.
- Lo que realmente sucedió.
- Notas (posiblemente incluyendo por qué crees que esto podría estar sucediendo, o cosas que intentaste y no funcionaron).

## Pull Requests

Damos la bienvenida activamente a tus Pull Requests (PRs).

1.  **Haz un fork** del repositorio y crea tu rama desde `main`.
2.  **Clona** el proyecto en tu máquina local.
3.  Si has añadido código que debe ser probado, añade pruebas.
4.  Si has cambiado APIs, actualiza la documentación.
5.  Asegúrate de que el conjunto de pruebas pase.
6.  Asegúrate de que tu código siga las convenciones de estilo existentes.
7.  ¡**Envía** esa Solicitud de Extracción!

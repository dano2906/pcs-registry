# Overview

**Our Pieces** is an open-source registry built on top of [shadcn-vue](https://www.shadcn-vue.com/). Its primary mission is to bridge the gap between the React and Vue ecosystems by porting popular, high-quality React components to Vue 3 with ease and precision.

This project is **not** a SaaS product or a component library in the traditional sense. Instead, it is a collection of copy-pasteable components designed to be integrated directly into your codebase, giving you full ownership and control over the code.

### Why Our Pieces?

The Vue ecosystem is vibrant, but it often lags behind React in terms of the sheer volume of available, high-quality UI components—especially those compatible with the modern "headless" or "radix-ui" philosophy popularized by shadcn/ui.

Our Pieces aims to solve this by focusing on:

1.  **Enriching the Ecosystem**: We actively identify useful React components that are missing or underrepresented in Vue and port them.
2.  **Flexible Distribution**: Components are designed to be copy-pasted or installed via CLI, allowing for maximum flexibility.
3.  **High Customizability**: Since you own the code, you can style and modify components to fit your exact needs without fighting against a library's API.
4.  **Modern Standards**: All components use modern Vue 3 syntax, including Composition API, TypeScript, and `<script setup>`.
5.  **Community Driven**: We are open to contributions. If you see a React component you love, help us bring it to Vue.
